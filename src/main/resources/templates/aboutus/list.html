Aflami Management System

A modern, high-performance web solution designed to simplify cinema administration, movie scheduling, customer management, and multimedia organization.

Version 1.0.0 Spring Boot 3.3.3 Java 21

Technology Stack

  • Framework Spring Boot 3.3.3 / Java 21
  • Frontend UI Thymeleaf + AdminLTE 4 + Bootstrap 5
  • Persistence Spring Data JPA + MySQL
  • Security Spring Security 6
  • Layout Dialect UltraQ Thymeleaf Layout Dialect

Platform Overview

Aflami is crafted to provide cinema managers with an intuitive workspace. With integrated analytics, seamless entity relations, and structured showtime management, cinema staff can handle everyday scheduling and ticketing workflows effortlessly.
